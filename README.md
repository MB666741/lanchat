# LanChat · 局域网聊天 / 文件传输

**同一个 Wi-Fi 或交换机下的电脑，打开就能互相找到，直接加密聊天、满速传文件。**
不需要服务器、不需要注册账号、不需要配对码 —— 消息只在你俩的机器之间跑。

Windows 上**解压即用**（对方电脑不需要装 Python）；也可以直接从源码运行。

![自测模式：同一台电脑上开两个真实窗口](docs/screenshot-selftest.png)

## 下载 & 上手（3 步）

1. 打开 [**Releases**](../../releases/latest)，下载 `LanChat-2.2.0-win64.zip`
2. 解压出**整个 LanChat 文件夹**（不要只拷 `LanChat.exe`，同目录的 `_internal\` 是它要用的）
3. 双击 `LanChat.exe` → 填个昵称 → 点「➕ 添加联系人」，选中对方 → 发送加好友请求；
   对方窗口会亮起 `🔔 新朋友`，点「同意」就能聊了

> **第一次运行 Windows 防火墙会弹窗 → 必须勾选「专用网络」并允许**，否则双方互相搜不到。
> 程序没有代码签名，SmartScreen 可能提示"未知发布者"，选「仍要运行」即可。

## 什么时候用得上

* **局域网里传大文件**：不想插 U 盘、不想走网盘（慢、还要压缩）—— 拖进去就是局域网满速，
  传完自动校验 SHA256，保证和原文件一模一样。
* **不想把聊天记录交给任何服务器**：本工具没有服务器，也没有账号体系；消息端到端加密，
  身份用"指纹"人工核对（和微信的安全码一个思路）。
* **只想让信得过的人加你**：加好友必须你点同意；可以给对方设**验证问题**（答错到上限自动封禁）；
  可以随时**封禁/解禁/删除好友**；还能开**隐身**（别人搜不到你，只有手填你的 IP 才能加）。

## 功能一览

| 功能 | 说明 |
| --- | --- |
| 自动发现 | 同一个局域网自动互相出现，不用填 IP、不用扫码 |
| 广播不通也能加 | Tailscale / WireGuard / 跨网段：在「添加联系人」里填对方 `IP`（自动问出端口）或 `IP:端口`；中文冒号、全角数字、多打的空格都会自动纠正 |
| 聊天 | 一对一私聊 + 一键群发给所有在线好友；带未读提示（正在看的那个对话不攒未读） |
| 传文件 | 可选保存位置、同名自动加序号不覆盖、整文件 SHA256 校验、支持大文件 |
| 好友管理 | 加好友需同意、验证问题、封禁/解禁、删除好友（对方会收到通知） |
| 端到端加密 | 每台设备一对身份密钥，每次连接现场协商新密钥，消息 AES-256-GCM 加密；**每 30 条消息自动换一把密钥**，传文件前后再各换一次 |
| 隐身模式 | 关掉「允许被自动搜索」→ 不广播、不回应探测，只能由对方手填你的 `IP:TCP端口` 加你 |
| 聊天记录 | **只在内存里**（关掉程序就没了，不留痕）；但一方还开着时，对方重启/重连会把缺的那段对话补发回去 |
| 自测模式 | 只有一台电脑也能验证全部流程：`--self-test` 会开两个真实窗口，还带「🧪 掉线 6 秒」按钮演练掉线重连 |

## 常见问题

| 现象 | 原因 / 怎么办 |
| --- | --- |
| 「添加联系人」里一个人都没有 | 对方没启动；不在同一网段/Wi-Fi；**防火墙没允许**（第一次必须勾「专用网络」）；对方开了**隐身**；或者你们是在 Tailscale/WireGuard 这类不跑广播的组网里 → 用下面的「手动添加」填对方 IP |
| 点了发送加好友请求，对方没提示 | 请求发不出去时程序会直接弹窗说明原因；对方需要在 `🔔 新朋友` 里点「同意」 |
| 搜不到但知道对方 IP | 在「添加联系人」底部填 `对方IP`（自动探测端口）或 `对方IP:对方TCP端口`（对方开了隐身时用这个） |
| 传输中断 / 一直"等待验证" | 对方离线了（上线后会自动重连）；或防火墙拦了 TCP |
| 怎么确认没有中间人 | 两边打开「设置」核对**身份指纹**是否一致（用别的渠道对，比如当面/电话） |
| 聊天记录会留下来吗 | 不会写硬盘：关掉程序就没了。只有"一方还开着"时，对方重新上线才会收到那段对话的补发 |
| 杀软 / SmartScreen 报警 | 程序没有代码签名，PyInstaller 打包的程序偶尔被误报；可自行从源码运行或按下面的说明打包 |

## 安全模型（简短版）

没有证书颁发机构，信任靠**人工核对指纹**建立（类似微信安全码）；之后每次连接都用**新的临时密钥**
（前向保密），旧密钥用完即弃。密文带认证，防篡改、防重放。

**已知边界**（说清楚比吹牛好）：局域网内的旁观者仍可做流量分析（知道谁和谁在通信、大约传了多少数据）；
消息加密前会做压缩和**随机长度补齐**，让"从包大小猜内容"失效，但**不能隐藏通信本身**。
对方离线且你本机没有记录时，消息发不出去。

## 开发者

```bash
pip install -r requirements.txt        # 只有 cryptography 一个第三方依赖
python chat_gui.py                     # 正常启动
python chat_gui.py --self-test         # 一台电脑模拟两个人
python chat_gui.py --diagnose          # 只做环境自检，不开界面
pyinstaller lanchat.spec --noconfirm   # 自己打包 → dist\LanChat\
```

原理、协议、加密细节、测试说明和**修复记录**都在 → [开发文档](docs/开发文档.md)。
