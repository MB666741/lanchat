局域网聊天 LanChat —— 文件夹版（免安装，对方电脑不需要装 Python）
====================================================================

怎么用
------
1. 把**整个 LanChat 文件夹**一起拷给对方（U盘/微信/网盘都行）。
   ⚠ 不能只拷 LanChat.exe —— 同目录下的那些 .dll / 文件夹都是它需要的。
2. 双击 LanChat.exe 就能用。第一次运行会让你填昵称。
3. 双方接在同一个局域网 / 同一个 Wi-Fi 时，会自动出现在对方的
   「➕ 添加联系人」列表里，选中后点『发送加好友请求』，对方点『同意』即可聊天。
   * Windows 防火墙第一次会弹窗：**必须勾选『专用网络』并允许**，否则互相搜不到。
4. 广播不通的网络（Tailscale / WireGuard / 跨网段 / 不同 VLAN）搜不到人，
   用「添加联系人」最下面的手动添加：
     * 只填对方 IP（例如 100.64.0.7）  → 程序单播问一句，自动拿到对方端口；
     * 填 IP:端口（例如 100.64.0.7:50606）→ 直接连（对方开了隐身时用这个）。
   打错的标点会自动纠正：中文冒号「：」、全角数字、空格、连 ` 一起粘进来都能认。
5. 隐身（只想让别人搜不到你）：⚙ 设置 → 关掉『允许被自动搜索』。
   之后别人只能手动填『你的IP:你的TCP端口』来加你 —— 建议同时在设置里把
   『本机端口』固定下来（不然每次重启端口都会变）。

界面语言
--------
* 自带三种界面语言：简体中文 / 繁體中文 / English，第一次启动跟随 Windows 的系统语言。
* 改语言：⚙ 设置 → 『界面语言』下拉框选一个 → 点『应用』，**重启程序后生效**。
* 临时用一次（不改设置）：命令行加 --lang，例如
      LanChat.exe --lang en            （English）
      LanChat.exe --lang zh-Hant       （繁體中文）
      LanChat.exe --lang zh-Hans       （简体中文）

文件和数据放在哪
----------------
* 身份密钥 / 好友列表 / 设置：  %USERPROFILE%\.lanchat
* 收到的文件：                系统下载目录\lanchat
卸载：直接删掉 LanChat 文件夹即可；想彻底清干净，把 %USERPROFILE%\.lanchat 也删掉。

聊天记录
--------
* 聊天内容**不保存到硬盘**：程序关掉就没了（故意的，不留痕迹）。
* 但只要**其中一方还开着**，另一方重启/重连回来以后，那一方会把这段对话补发给他，
  所以重启后还能看到刚才聊了什么（包括自己说过的话）。
* 对方不在线时你照样可以发：消息先存在你本机，他一上线自动补发过去。
* 两边都关掉 → 这段对话就彻底没了。切换联系人不会丢（程序运行期间都记着）。

安全吗
------
* 每个设备一对 Ed25519 身份密钥；每次连接都用 X25519 现场协商，
  会话密钥由 HKDF 派生，消息用 AES-256-GCM 加密并认证（防篡改/防重放）。
* 密钥每收发 30 条消息自动轮换一次，旧的立刻作废（补发历史时用的也是当前密钥）。
* **传文件会单独换两次密钥**：对方点"同意接收"时换一把（文件不用聊天那把），传完再换一把
  把那一轮退役。
* 每条消息加密前会先压缩、再做**随机长度补齐**：别人光看"包多大"也猜不出你打了几个字
  （代价是每条小消息多传几百字节，局域网里可以忽略）。
* 真正确认"没有中间人"的办法：和对方用别的渠道（当面/电话）核对
  ⚙ 设置 里显示的身份指纹是否一致。

排查
----
在 cmd 里执行（能看到详细日志）：
    LanChat.exe --diagnose > out.txt
自测（同一台电脑开两个窗口，验证功能是否正常）：
    LanChat.exe --self-test
